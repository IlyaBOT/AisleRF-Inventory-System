# AisleRF Inventory System

AisleRF - веб-приложение для домашней инвентаризации и учёта хранения радиоэлектронных компонентов: микросхем, модулей, деталей, расходников и т.д. на "складе" (Будь то реальный склад, или шкаф/тумбочка позади вас). Проект рассчитан как на использование одним человеком, так и на использование в малом офисе (порядка 15–20 пользователей) и параллельную работу через несколько аккаунтов.

Внимание! Проект делался в первую очередь для личного использования и под личные нужны разработчика. Если вас что-то не устраивает или вы хотите добавить функционал - сделайте форк проекта и киньте пулл-реквест, если мне понравится, я добавлю его в основную ветку.

## Текущие возможности проекта:

- Авторизация и сессии (JWT).
- Несколько складов (по умолчанию создаётся `default`), быстрое переключение между складами.
- Лоты имеют UID (Уникальный ID номер с автоинкрементом в диапазоне от 1 до 4294967294).
- Лот имеет поля:
- - Название 
- - Описание
- - Количество
- - Цена + валюта (опционально)
- - Источник покупки (Название маркетплейса с вложенной ссылкой) (опционально)
- - Категории
- - Теги
- - Фото (опционально)
- Загрузка фото: автоматическое уменьшение до 128x128 -> JPEG-сжатие с качеством 70% -> Преобразование в Base64 -> Запись в БД.
- Система поиска и гибкая-фильтрация *как на маркетплейсах*: текстовый поиск, категории, использование тегов, диапазон цен.
- Дэшборд: Общая статистика и списки компонентов (последние добавленные/использованные, топ по количеству, частота использования).
- Dev-режим: отдельная вкладка Debug с системной информацией.

## Разделы интерфейса

- Login - вход в систему.
- Dashboard - Дэшборд с основной информацией, является главной страницей.
- Storage - Список и создание лотов, фильтрация, выбор и создание склада.
- System - Настройки системы.
- Debug - только в [Dev] режиме, используется для разработки и отладки.

## Технологии

Backend:
- Python FastAPI
- PostgreSQL.
- SQLAlchemy, Alembic
- REST API, JWT

Frontend:
- TypeScript
- React (Vite)

Инфраструктура:
- Docker-compose
- Dev и Prod профили

## Запуск при помощи Docker Compose 
### Настройка переменных окружения
```bash
cp .env.example .env
```

### Dev Mode (hot-reload, Debug вкладка)
```bash
docker compose --profile dev up --build
```

- UI: http://localhost:5173
- API: http://localhost:8000
- Swagger: http://localhost:8000/docs

### Prod/Release Mode (сборка фронта и nginx)
```bash
docker compose --profile prod up --build -d
```
- UI + API через nginx: http://localhost:8080
- Swagger: http://localhost:8080/api/docs

### Остановка и очистка томов
```bash
docker compose down -v
```
